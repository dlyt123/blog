# ================================================================
# 内置敏感词基础库
#
# 格式：分类|词语     （# 开头为注释，空行忽略）
#
# 设计原则 —— 「宁可漏，不可误杀」：
#   误杀正常用户的代价，远比漏掉几个广告大。
#   所以这里一律用【组合词】而不是【宽泛的单词】：
#     ✗ 错：「兼职」——正常讨论兼职也会被拦
#     ✓ 对：「兼职日结」「高薪兼职」——指向明确的黑产话术
#     ✗ 错：「贷款」——正常讨论贷款也会被拦
#     ✓ 对：「贷款包过」「无抵押秒批」——这才是诈骗话术
#
# 本文件随 jar 一起部署，服务器不需要额外执行 SQL。
# 管理员在后台「敏感词管理」里增删的词存数据库，与本文件【合并生效】。
#
# ⚠️ 说明：本文件只覆盖【广告 / 赌博 / 违法 / 诈骗 / 色情 / 辱骂 / 黑产】这类
#    通用风控词。**政治类敏感内容不在此文件内**，那部分建议接入合规的
#    内容安全服务（如阿里云内容安全）来做，比静态词库可靠得多。
# ================================================================
